// Featured project

Building with care.

MindCheck

AI-assisted mental wellness screening

  • Full-stack web app for student wellness check-ins: a chat-style 10-question flow, results, history with a trend chart, and a resources section.
  • Flask REST API serving a scikit-learn model; I compared Logistic Regression against Random Forest and picked the winner on macro-F1.
  • Lexicon-based NLP sentiment analysis on free-text notes, fed to the model as a feature.
  • A rule-based safety layer screens for urgent language before any scoring, and the app falls back to rule-based scoring if the API is offline.
  • Built on a synthetic dataset and clearly labelled as a demonstration model, not clinically validated.
